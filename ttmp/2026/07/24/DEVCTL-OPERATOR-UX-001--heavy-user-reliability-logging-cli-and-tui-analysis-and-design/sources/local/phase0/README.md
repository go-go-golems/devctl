# Phase 0 Baseline and Consumer Gate

These files are the reproducible pre-implementation baseline for
DEVCTL-OPERATOR-UX-001. They were generated by `scripts/05-phase0-baseline.sh`
and `scripts/06-phase0-consumer-gate.sh` at commit `3adb8d7`, before production
code changed.

## Baseline result

The unrestricted baseline passed:

- `go test ./...`
- `go build ./...`
- `make lint`
- architecture inventory probe
- CLI contract probe
- log-follow lifecycle probe
- tmux TUI state-event probe

The first restricted-sandbox run failed VCS stamping, lint package loading,
and tmux access. Re-running the same script with normal repository and tmux
access passed every command. `summary.tsv` records the authoritative second
run.

The log lifecycle capture proves the current follower emits an appended line
but loses both the post-truncation and post-rotation lines. The TUI capture
proves that a missing state file creates a new identical event on every poll.

## Removal gate

`external-logjs-imports.txt` contains zero external imports after excluding
devctl itself. The `pkg/logjs` and `cmd/log-parse` removal gate therefore
passes: no extraction ticket or compatibility adapter is required.

`external-legacy-cli-uses.txt` contains 42 references outside devctl. Most are
historical Obsidian articles, but active documentation or scripts also exist
in `publish-vault`, `scraper`, `rag-evaluation-system`, and `researchctl`.
These do not block the deliberate CLI break. They are an explicit downstream
migration inventory for Phase 7.

## Files

- `summary.tsv`: exit status and output path for every baseline command.
- `go-test.txt`, `go-build.txt`, `make-lint.txt`: build-system evidence.
- `probe-01.txt` through `probe-04.txt`: architecture and behavior captures.
- `consumer-gate-summary.tsv`: downstream match counts.
- `external-logjs-imports.txt`: extraction-gate evidence.
- `external-legacy-cli-uses.txt`: downstream CLI migration inventory.
- `go-work-files.txt`: discovered Go workspace roots.
